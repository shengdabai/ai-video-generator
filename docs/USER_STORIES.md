## 八、验收清单

### MVP 验收清单

- [ ] **用户系统**
  - [ ] 用户可以使用手机号注册
  - [ ] 用户可以使用手机号+验证码/密码登录
  - [ ] 新用户获得 3 次免费生成机会
  
- [ ] **视频创作**
  - [ ] 用户可以输入 10-500 字场景描述
  - [ ] AI 在 5 秒内返回增强后的描述
  - [ ] 系统自动生成 1-5 个分镜
  - [ ] 用户可以编辑分镜内容
  - [ ] 用户可以选择视频风格模板
  
- [ ] **视频生成**
  - [ ] 系统在 5 分钟内生成 30 秒视频
  - [ ] 生成过程有进度提示
  - [ ] 支持后台生成+通知
  
- [ ] **视频输出**
  - [ ] 用户可以预览生成的视频
  - [ ] 用户可以下载 720p MP4 视频
  - [ ] 免费版视频带有水印
