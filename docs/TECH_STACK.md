## 二、移动端技术选型

### 2.1 技术方案对比

| 方案 | iOS | Android | 优势 | 劣势 | 推荐度 |
|-----|-----|---------|-----|-----|-------|
| **原生开发** | Swift/SwiftUI | Kotlin/Compose | 性能最优，体验最佳 | 开发成本高，需两套代码 | ⭐⭐⭐⭐ |
| **React Native** | JavaScript | JavaScript | 一套代码，生态成熟 | 性能次于原生，复杂UI受限 | ⭐⭐⭐ |
| **Flutter** | Dart | Dart | 一套代码，UI一致性好 | 包体积大，学习成本 | ⭐⭐⭐⭐ |
| **Expo** | JavaScript | JavaScript | 开发快速，热更新 | 性能受限，原生功能少 | ⭐⭐ |

### 2.2 推荐方案：React Native + Expo

**选择理由**:
1. **快速迭代**: MVP 阶段需要快速验证，跨平台节省开发时间
2. **团队技能**: 前端开发者可快速上手
3. **生态成熟**: 丰富的第三方库支持
4. **热更新**: 支持 OTA 更新，无需发版
5. **后期迁移**: 可逐步迁移到原生获得更好性能

**技术栈明细**:

| 层级 | 技术选型 | 说明 |
|-----|---------|------|
| **框架** | React Native 0.73+ | 跨平台框架 |
| **工具链** | Expo SDK 50 | 简化开发流程 |
| **状态管理** | Zustand | 轻量级状态管理 |
| **网络请求** | Axios + React Query | 请求缓存和状态 |
| **导航** | React Navigation 6 | 页面导航 |
| **UI 组件** | NativeWind (TailwindCSS) | 样式方案 |
| **视频播放** | expo-av | 视频播放器 |
| **本地存储** | MMKV | 高性能存储 |
| **推送通知** | Expo Notifications | 推送服务 |
| **支付** | RevenueCat | 跨平台订阅 |

## 六、数据库设计概要

### 6.1 核心表结构

```sql
-- 用户表
CREATE TABLE users (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    phone           VARCHAR(20) UNIQUE,
    password_hash   VARCHAR(255),
    nickname        VARCHAR(50),
    avatar_url      VARCHAR(500),
    membership      VARCHAR(20) DEFAULT 'free',  -- free/pro/business
    credits         INTEGER DEFAULT 3,           -- 剩余生成次数
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 视频项目表
CREATE TABLE video_projects (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID REFERENCES users(id),
    title           VARCHAR(200),
    original_prompt TEXT,                        -- 原始用户输入
    enhanced_prompt TEXT,                        -- AI 增强后的描述
    style_template  VARCHAR(50),                 -- 风格模板
    status          VARCHAR(20) DEFAULT 'draft', -- draft/processing/completed/failed
    duration        INTEGER,                     -- 视频时长(秒)
    video_url       VARCHAR(500),                -- 最终视频URL
    thumbnail_url   VARCHAR(500),                -- 缩略图URL
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 分镜表
CREATE TABLE storyboards (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id      UUID REFERENCES video_projects(id),
    scene_index     INTEGER,                     -- 场景顺序
    prompt          TEXT,                        -- 场景描述
    duration        INTEGER,                     -- 时长(秒)
    video_clip_url  VARCHAR(500),                -- 片段URL
    status          VARCHAR(20) DEFAULT 'pending',
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 订阅记录表
CREATE TABLE subscriptions (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID REFERENCES users(id),
    plan            VARCHAR(20),                 -- pro/business
    status          VARCHAR(20),                 -- active/cancelled/expired
    start_date      TIMESTAMP,
    end_date        TIMESTAMP,
    payment_id      VARCHAR(100),                -- 第三方支付ID
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 生成任务表
CREATE TABLE generation_tasks (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id      UUID REFERENCES video_projects(id),
    storyboard_id   UUID REFERENCES storyboards(id),
    engine          VARCHAR(50),                 -- runway/pika/kling
    status          VARCHAR(20),                 -- pending/running/completed/failed
    progress        INTEGER DEFAULT 0,           -- 0-100
    result_url      VARCHAR(500),
    error_message   TEXT,
    started_at      TIMESTAMP,
    completed_at    TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);
```

### 6.2 索引设计

```sql
-- 用户查询优化
CREATE INDEX idx_users_phone ON users(phone);
CREATE INDEX idx_users_membership ON users(membership);

-- 项目查询优化
CREATE INDEX idx_projects_user_id ON video_projects(user_id);
CREATE INDEX idx_projects_status ON video_projects(status);
CREATE INDEX idx_projects_created ON video_projects(created_at DESC);

-- 任务状态查询
CREATE INDEX idx_tasks_status ON generation_tasks(status);
CREATE INDEX idx_tasks_project ON generation_tasks(project_id);
```

## 七、安全设计

### 7.1 安全措施矩阵

| 安全领域 | 措施 | 实现方式 |
|---------|------|---------|
| **传输安全** | HTTPS 全链路 | Let's Encrypt / 云SSL证书 |
| **身份认证** | JWT Token | Access Token + Refresh Token |
| **密码存储** | bcrypt 哈希 | 加盐哈希，迭代 12 轮 |
| **API 安全** | 签名验证 | HMAC-SHA256 请求签名 |
| **限流** | 速率限制 | Redis 滑动窗口 |
| **内容安全** | 敏感词过滤 | 阿里云内容安全 |
| **数据加密** | 敏感字段加密 | AES-256 |
| **日志脱敏** | 敏感信息脱敏 | 手机号/密码脱敏 |
