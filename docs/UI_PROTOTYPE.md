# VidCraft AI - UI 原型与交互设计

## 一、设计规范

### 1.1 设计原则

| 原则 | 说明 |
|-----|------|
| **简洁直观** | 减少学习成本，用户 3 步完成核心操作 |
| **反馈及时** | 每个操作都有明确的视觉反馈 |
| **情感化** | 等待过程有趣味性，降低焦虑 |
| **一致性** | 组件、交互、文案风格统一 |

### 1.2 色彩规范

```
主色调 (Primary)
┌────────────────────────────────────────────────────────────────┐
│  #6366F1 (靛紫色)    - 主按钮、重要操作                        │
│  #818CF8 (浅紫色)    - 次要元素、Hover 状态                    │
│  #4F46E5 (深紫色)    - 按下状态、强调                          │
└────────────────────────────────────────────────────────────────┘

辅助色 (Secondary)
┌────────────────────────────────────────────────────────────────┐
│  #10B981 (绿色)      - 成功状态                                │
│  #F59E0B (橙色)      - 警告状态                                │
│  #EF4444 (红色)      - 错误状态                                │
│  #3B82F6 (蓝色)      - 信息提示                                │
└────────────────────────────────────────────────────────────────┘

中性色 (Neutral)
┌────────────────────────────────────────────────────────────────┐
│  #FFFFFF             - 背景（浅色模式）                        │
│  #F9FAFB             - 次级背景                                │
│  #111827             - 主文字                                  │
│  #6B7280             - 次级文字                                │
│  #E5E7EB             - 分割线、边框                            │
└────────────────────────────────────────────────────────────────┘
```

### 1.3 字体规范

| 用途 | 字体 | 字号 | 字重 |
|-----|------|------|-----|
| 大标题 | SF Pro / Noto Sans SC | 28px | Bold |
| 标题 | SF Pro / Noto Sans SC | 20px | Semibold |
| 正文 | SF Pro / Noto Sans SC | 16px | Regular |
| 辅助文字 | SF Pro / Noto Sans SC | 14px | Regular |
| 小字 | SF Pro / Noto Sans SC | 12px | Regular |
